Logical Program 09 ES6 Template Strings

Template Literal Function

Uses ES6 backtick interpolation `...${expression}...` to build formatted dynamic greeting strings.

JavaScript Implementation:
function introduce(name, age) {
  return `My name is ${name} and I am ${age} years old.`;
}
console.log(introduce("Ravi", 25));
Execution Output:
"My name is Ravi and I am 25 years old."

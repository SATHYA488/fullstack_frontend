Logical Program 08 Function Declarations vs Expressions

Square Function in 3 Different Ways

Demonstrates Function Declaration, Function Expression, and ES6 Arrow Function.

JavaScript Implementation:
// 1. Function Declaration
function square1(n) {
  return n * n;
}

// 2. Function Expression
const square2 = function(n) {
  return n * n;
};

// 3. Arrow Function
const square3 = (n) => n * n;

console.log(square1(5), square2(5), square3(5)); // 25 25 25
Execution Output:
square1(5) = 25 | square2(5) = 25 | square3(5) = 25

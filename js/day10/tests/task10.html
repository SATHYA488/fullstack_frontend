Logical Program 10 Block vs Function Scope

Var / Let / Const Scope Demonstration

Demonstrates that var leaks outside block scope `{ ... }`, whereas let and const are block-scoped.

JavaScript Implementation:
{
  var a = 10;  // function/global scoped
  let b = 20;  // block scoped
  const c = 30;// block scoped
}

console.log(a); // Output: 10 (Accessible)
// console.log(b); // ReferenceError: b is not defined
// console.log(c); // ReferenceError: c is not defined
Execution Output:
`var a` leaks outside block → console.log(a) = 10
`let b` and `const c` remain protected inside block scope.

Object Student Details Iteration

Iterates through an array of student objects printing details for each record.

JavaScript Implementation:
let student = [
  { name: "Ravi", age: 22, course: "JavaScript", mark: 85 },
  { name: "ram", age: 24, course: "JavaScript", mark: 89 },
  { name: "suman", age: 27, course: "JavaScript", mark: 67 },
  { name: "krish", age: 23, course: "JavaScript", mark: 75 }
];

for (let a = 0; a < student.length; a++) {
  console.log(student[a]);
}
Execution Output:
1. Ravi (Age: 22, Course: JS, Mark: 85)
2. Ram (Age: 24, Course: JS, Mark: 89)
3. Suman (Age: 27, Course: JS, Mark: 67)
4. Krish (Age: 23, Course: JS, Mark: 75)

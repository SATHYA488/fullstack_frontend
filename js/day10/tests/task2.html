Factorial of a Number using While Loop

Calculates the factorial of 5 (5! = 5 × 4 × 3 × 2 × 1 = 120) using a while loop iteration.

JavaScript Implementation:
let num = 5; 
let fact = 1;
let i = 1;

while (i <= num) {
  fact *= i;
  i++;
}
console.log(fact); // Output: 120
Execution Output:
Factorial of 5 = 120

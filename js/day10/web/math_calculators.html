1. Factorial (n!)
O(N) Linear

Definition: The product of all positive integers less than or equal to $n$, with base case $0! = 1$.

n! = n × (n-1) × ... × 1
Use Case: Combinatorics & Permutations ($^n P_r$).
n =
5! = 120
2. Sum of Numbers
O(N) Fold

Definition: The total scalar aggregate obtained by the commutative addition of a set of values.

Sum = Σ x = a1 + a2 + ... + an
Use Case: Financial balances & Cart totals.
Sum([10, 20, 30, 40]) = 100
3. Average (Mean)
O(N) Statistics

Definition: The primary measure of central tendency representing total sum divided by sample count ($n$).

Mean (μ) = (Σ x) / n
Use Case: Grade point averages (GPA), benchmark KPIs.
Average([10..50]) = 30
4. Square (x²)
O(1) Quadric

Definition: The product of multiplying a number by itself, representing geometric 2D quadric area.

Square(x) = x × x = x²
Use Case: Quadratic equations & Euclidean distances.
x =
7² = 49
5. Cube (x³)
O(1) Cubic

Definition: The product of multiplying a number by itself twice, representing 3D volumetric space.

Cube(x) = x × x × x = x³
Use Case: 3D spatial simulations & Volume metrics.
x =
4³ = 64
6. Power (x^y)
O(1) Exponent

Definition: Exponential scaling representing base $x$ multiplied by itself $y$ times ($x^0 = 1$).

Power = Math.pow(x, y) = x^y
Use Case: Cryptographic keys & Scientific scales.
2^5 = 32
7. Multiplication
O(1) Arithmetic

Definition: The fundamental arithmetic operation scaling a multiplicand by a multiplier.

Product = a × b
Use Case: Item pricing × quantity calculations.
12 × 8 = 96
8. Percentage (%)
O(1) Proportional

Definition: Dimensionless proportional ratio expressed as a fraction of 100.

% = (Part / Total) × 100
Use Case: Tax percentages, performance margins.
45 of 50 = 90.00%
9. Simple Interest (SI)
O(1) Linear

Definition: Linear financial interest accrued strictly on the original uncompounded principal amount.

SI = (P × R × T) / 100
Use Case: Short-term bonds, automotive financing.
SI = $1,500 | Total = $11,500
10. Compound Interest
O(1) Exponential

Definition: Exponential capital growth where interest earns interest over consecutive cycles.

A = P(1 + r/n)^(nt)
Use Case: Mutual funds, banking deposits, mortgages.
CI = $1,576.25 | Total = $11,576.25
11. Area (Rectangle)
O(1) 2D Space

Definition: Two-dimensional surface capacity contained within the shape boundary.

Area = Length × Width
Use Case: Real estate floor plans & Canvas sizing.
Area = 10 × 5 = 50 sq units
12. Perimeter
O(1) 1D Boundary

Definition: Total continuous linear distance encompassing a closed 2D polygon path.

Perimeter = 2(L + W)
Use Case: Fencing, framing, CSS border outlines.
Perimeter = 2(10 + 5) = 30 units
13. Volume (Cuboid)
O(1) 3D Capacity

Definition: Total three-dimensional space occupied by a solid closed body.

Volume = L × W × H
Use Case: Container shipping capacity & Warehousing.
Volume = 4 × 3 × 5 = 60 cubic units
14. Speed / Distance / Time
O(1) Kinematics

Definition: Kinematic rate of change describing distance covered over elapsed unit time.

Speed = Distance / Time
Use Case: GPS routing, vehicle telemetry, ETA computation.
Speed = 150 km / 3 hr = 50 km/h
15. Profit & Loss
O(1) Commercial

Definition: Commercial net margin calculated between Selling Price (SP) and Cost Price (CP).

Profit = SP - CP | % = (Profit/CP)×100
Use Case: Retail margin analytics & Trading PnL.
Profit = +$50.00 (+25.00%)
16. Discount
O(1) Retail

Definition: Concession deducted from marked price to calculate net consumer billing.

Disc = Marked × (Disc% / 100)
Use Case: Black Friday promos, coupon codes.
Disc = -$100 | Final = $400.00
17. LCM (Least Common Multiple)
O(log N) Euclid

Definition: The smallest positive integer divisible by two integers $a$ and $b$.

LCM(a, b) = |a × b| / GCD(a, b)
Use Case: Periodic event synchronizing, gear trains.
LCM(12, 18) = 36
18. GCD / HCF
O(log(min(a,b)))

Definition: Highest common integer dividing two numbers without remainder via Euclidean division.

Euclidean Algorithm: GCD(a, b) = GCD(b, a%b)
Use Case: Cryptography (RSA Keygen) & Fraction simplification.
GCD(48, 18) = 6
19. Arithmetic Progression (AP)
O(N) Sequence

Definition: Uniform discrete sequence with constant common difference $d$ between terms.

an = a + (n-1)d | Sn = (n/2)[2a+(n-1)d]
Use Case: Loan depreciation schedules, ladder pricing.
[3, 5, 7, 9, 11] | a5=11 | Sum=35
20. Fibonacci Series
O(N) Recurrence

Definition: Recurrence sequence where each term is the sum of preceding two: $F_n = F_{n-1} + F_{n-2}$.

F(n) = F(n-1) + F(n-2) | Φ ≈ 1.618
Use Case: Golden ratio UI design, Agile sprint estimations.
n terms:
[0, 1, 1, 2, 3, 5, 8, 13]
21. Sum of Natural Series
O(1) Gauss Closed

Definition: Carl Friedrich Gauss closed-form summation of first $n$ positive natural integers.

Sn = n(n + 1) / 2
Use Case: Loop complexity reduction from $O(N)$ to $O(1)$.
n =
1 + 2 + ... + 10 = 55

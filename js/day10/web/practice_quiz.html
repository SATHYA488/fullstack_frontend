Question 1 • Array Methods
Which method transforms each array element without mutating the original array?
Explanation: map() creates a brand new array populated with the results of calling a provided function on every element, preserving immutability.
Question 2 • Arithmetic & Loops
What is the mathematical output of factorial(5) ($5!$)?
Explanation: \(5! = 5 \times 4 \times 3 \times 2 \times 1 = 120\).
Question 3 • Number Theory
What is the Greatest Common Divisor (GCD) of 48 and 18?
Explanation: Using the Euclidean algorithm: \(\text{GCD}(48, 18) = \text{GCD}(18, 12) = \text{GCD}(12, 6) = 6\).
Question 4 • Scope & TDZ
What occurs when accessing a let variable before its declaration?
Explanation: let and const reside in the Temporal Dead Zone (TDZ) from the start of the block until the declaration is processed.
Question 5 • Financial Math
What is the Simple Interest on $10,000 at 5% per annum for 3 years?
Explanation: \(\text{SI} = \frac{P \times R \times T}{100} = \frac{10000 \times 5 \times 3}{100} = \$1,500\).
Question 6 • Higher-Order Reducers
What does [10, 20, 30].reduce((sum, val) => sum + val, 0) return?
Explanation: reduce() executes the reducer callback, accumulating \(0 + 10 + 20 + 30 = 60\).
Question 7 • Sequences
What are the first 6 terms of the Fibonacci sequence?
Explanation: \(F(0)=0, F(1)=1, F(2)=1, F(3)=2, F(4)=3, F(5)=5\).
Question 8 • Modern CSS
What is the core architectural philosophy behind Tailwind CSS?
Explanation: Tailwind CSS uses utility classes directly in markup to build custom responsive interfaces with JIT compilation.

Question 01 • Loops Comparison
What is the difference between for loop, while loop, and do...while loop? When would you choose each one?
Answer & Breakdown:
Loop TypeCondition CheckMinimum ExecutionsWhen to Choose
forEntry-controlled (at the start)0 timesWhen number of iterations is known beforehand (e.g., iterating an array by length).
whileEntry-controlled (at the start)0 timesWhen iterations depend on a dynamic condition (e.g., waiting for a flag or user input).
do...whileExit-controlled (at the end)1 time guaranteedWhen the code block must execute at least once before condition evaluation (e.g., displaying a menu).
 
// for loop: known iterations
for (let i = 0; i < 5; i++) { console.log(i); }

// while loop: condition-based
let count = 3;
while (count > 0) { console.log(count--); }

// do...while loop: executes at least once
let num = 10;
do {
  console.log("Runs once even if condition false:", num);
} while (num < 5);
Question 02 • Functions Taxonomy
Explain the difference between a normal function, function expression, and arrow function with suitable examples.
Answer & Key Distinctions:
  • Function Declaration: Hoisted completely (can be called before its definition in code). Has its own this and arguments binding.
  • Function Expression: Stored inside a variable. Hoisting depends on variable declaration (e.g., let/const in TDZ).
  • Arrow Function (ES6): Concise syntax, implicit return support. Does not bind its own this (inherits lexical this), cannot be used as a constructor with new.
// 1. Function Declaration (Hoisted)
function greet(name) {
  return "Hello " + name;
}

// 2. Function Expression (Not hoisted before initialization)
const square = function(n) {
  return n * n;
};

// 3. Arrow Function (Lexical this & concise implicit return)
const add = (a, b) => a + b;

console.log(greet("Sakthi"), square(4), add(10, 20));
Question 03 • Parameters vs Arguments
What are parameters and arguments? Explain the difference between them.
Answer:
  • Parameters: The named placeholder variables declared in the function's signature definition.
  • Arguments: The real concrete values passed into the function when it is invoked.
// 'price' and 'taxRate' are PARAMETERS (Placeholders)
function calculateBill(price, taxRate) {
  return price + (price * taxRate);
}

// 500 and 0.18 are ARGUMENTS (Actual Values passed)
console.log(calculateBill(500, 0.18)); // 590
Question 04 • Scope in JavaScript
What is scope in JavaScript? Explain global scope, function scope, and block scope.
Answer: Scope defines the accessibility/visibility of variables, functions, and objects in different execution contexts.
  1. Global Scope: Variables declared outside any function/block; accessible everywhere in the script.
  2. Function Scope: Variables declared inside a function (using var, let, or const) are only accessible within that function.
  3. Block Scope (ES6): Variables declared with let and const inside curly brackets { ... } (such as if, for) cannot be accessed outside the block.
let globalVar = "Global"; // Global Scope

function testScope() {
  var funcVar = "Function-Scoped"; // Function Scope
  if (true) {
    let blockVar = "Block-Scoped";  // Block Scope
    const blockConst = "Constant";  // Block Scope
    console.log(blockVar, blockConst);
  }
  // console.log(blockVar); // ReferenceError: blockVar is not defined
}
Question 05 • Hoisting & TDZ
What is hoisting? Explain how var, let, and const behave during hoisting and what TDZ means.
Answer:
  • Hoisting: JavaScript engine's behavior of allocating memory for variable and function declarations during the Creation Phase before code execution.
  • var Hoisting: Hoisted and initialized with undefined. Accessing it before declaration returns undefined without crashing.
  • let & const Hoisting: Hoisted into memory but remain uninitialized.
  • Temporal Dead Zone (TDZ): The time window between entering scope and the line where let/const is initialized. Accessing a variable in its TDZ throws a ReferenceError.
console.log(a); // undefined (var is hoisted and initialized to undefined)
var a = 10;

// console.log(b); // ReferenceError: Cannot access 'b' before initialization (TDZ)
let b = 20;

Question 08 • Factorial Calculation
Write a program to calculate the factorial of a given number.
function getFactorial(num) {
  let fact = 1;
  let i = 1;
  while (i <= num) {
    fact *= i;
    i++;
  }
  return fact;
}
console.log("Factorial of 5:", getFactorial(5)); // 120
Output: Factorial of 5: 120
Question 09 • Fibonacci Series for n terms
Write a program to print the Fibonacci series for n terms.
function printFibonacci(n) {
  let fib = [0, 1];
  for (let i = 2; i < n; i++) {
    fib.push(fib[i - 1] + fib[i - 2]);
  }
  return fib.slice(0, n);
}
console.log("Fibonacci (8 terms):", printFibonacci(8));
Output: [0, 1, 1, 2, 3, 5, 8, 13]

Question 11 • Array Mutators (push, pop, unshift, shift)

// 1. Add product at the end (push)
products.push("Smartwatch");
console.log("After push:", products); // ["Laptop", "Phone", "Tablet", "Smartwatch"]

// 2. Remove the last product (pop)
let removedLast = products.pop();
console.log("Popped:", removedLast, "| Array:", products); // ["Laptop", "Phone", "Tablet"]

// 3. Add product at the beginning (unshift)
products.unshift("Monitor");
console.log("After unshift:", products); // ["Monitor", "Laptop", "Phone", "Tablet"]

// 4. Remove the first product (shift)
let removedFirst = products.shift();
console.log("Shifted:", removedFirst, "| Final Array:", products); // ["Laptop", "Phone", "Tablet"]
Output: Final Products Array: ["Laptop", "Phone", "Tablet"]

Question 15 • Shop Discount via Ternary Operator
A shop gives a discount based on the bill amount. If the bill amount is greater than or equal to 1000, display 'Discount Applied'; otherwise display 'No Discount'. Solve this using the ternary operator.
function checkShopDiscount(billAmount) {
  let message = (billAmount >= 1000) ? "Discount Applied" : "No Discount";
  return `Bill: $${billAmount} → ${message}`;
}

console.log(checkShopDiscount(1250)); // Bill: $1250 → Discount Applied
console.log(checkShopDiscount(850));  // Bill: $850 → No Discount

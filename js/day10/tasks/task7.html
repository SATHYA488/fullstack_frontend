Topic 07 Asynchronous JS

Promises & Async / Await

Handles asynchronous operations without callback hell using Promises and async/await syntax.

JavaScript Implementation:
const fetchData = () => {
  return new Promise((resolve, reject) => {
    setTimeout(() => resolve("Data fetched successfully!"), 500);
  });
};

fetchData().then(data => console.log(data));
Execution Output:
Promise resolved → "Data fetched successfully!"

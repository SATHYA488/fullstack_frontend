Arrow Functions (Implicit vs Explicit Return)

Demonstrates standard functions, explicit arrow functions with curly braces, and concise implicit return arrow functions.

JavaScript Implementation:
// Explicit Arrow Function
const sum = (c, d) => {
  return c + d;
};

// Implicit Arrow Function
const value = (a, b) => a + b;

console.log(sum(10, 20)); // 30
console.log(value(5, 15)); // 20

cube(5) = 25

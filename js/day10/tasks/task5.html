Topic 05 ES6 Functions

Default Function Parameters

Allows function parameters to be initialized with default fallback values if no value or undefined is passed.

JavaScript Implementation:
function greet(name = "Guest", role = "Viewer") {
  return `Welcome, ${name}! Your role is: ${role}`;
}

console.log(greet()); // Welcome, Guest! Your role is: Viewer
console.log(greet("Sakthi", "Admin")); // Welcome, Sakthi! Your role is: Admin
Execution Output:
greet() → "Welcome, Guest! Your role is: Viewer"
greet("Sakthi", "Admin") → "Welcome, Sakthi! Your role is: Admin"

Topic 08 ES2020 Feature

Optional Chaining (?.)

Safely reads deep nested properties without throwing TypeError: Cannot read property of undefined.

JavaScript Implementation:
const profile = {
  name: "Sakthi",
  contact: {
    email: "sakthi@example.com"
  }
};

console.log(profile?.contact?.email); // sakthi@example.com
console.log(profile?.address?.zipCode); // undefined (Safe, no crash!)
Execution Output:
profile?.contact?.email → "sakthi@example.com"
profile?.address?.zipCode → undefined (Safe Execution)

Topic 01 Language Mechanism

Hoisting & Temporal Dead Zone (TDZ)

Explains scope boundaries, variable hoisting with var vs the Temporal Dead Zone (TDZ) for let and const.

JavaScript Implementation:
function scopeTest() {
  if (true) {
    var x = "var inside block";
    let y = "let inside block";
    const z = "const inside block";
    console.log("Inside block:", x, y, z);
  }
  console.log("Outside block:", x); // var is accessible
}
scopeTest();
Execution Output:
Inside block: var inside block let inside block const inside block
Outside block: var inside block

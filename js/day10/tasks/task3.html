Topic 03 ES6 Feature

Array & Object Destructuring

Extracts values from arrays and objects cleanly into distinct variables.

JavaScript Implementation:
// Object Destructuring
const user = { name: "Sakthi", role: "Developer", city: "Chennai" };
const { name, role, city } = user;
console.log(name, role, city);

// Array Destructuring
const colors = ["Red", "Green", "Blue"];
const [first, second, third] = colors;
console.log(first, second, third);
Execution Output:
User: Sakthi | Developer | Chennai
Colors: Red, Green, Blue
